# Publishing

Esta seccion final representa la salida del flujo: convertir el contenido en un entregable listo para compartir.

## Formatos

- PDF
- HTML

Word/DOCX y EPUB existen en la implementacion interna, pero no se muestran en la UI publica de la version 1 y quedan reservados como funcionalidades Pro futuras.
