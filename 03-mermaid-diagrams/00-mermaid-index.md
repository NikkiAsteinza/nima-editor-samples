# Mermaid Diagram Index

This folder contains one sample per Mermaid diagram family supported by the editor runtime.

## Core diagrams

- Flowchart and graph alias
- Sequence, class, state, ER, journey, Gantt, pie
- GitGraph, mindmap, timeline, XY chart

## Mermaid 11 families

- Quadrant, requirement, C4, ZenUML, Sankey, block, packet, Kanban
- Architecture, radar, event modeling, treemap, Venn, Ishikawa, Wardley, TreeView

Each file favors one dense example over many tiny examples, so the editor panel can expose as many controls as possible from a single diagram.
